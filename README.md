# ljh-mi

CyberDog simulation and motion-control notes, including a ROS 2/Gazebo pose monitor script and collected operations references.

## Contents

- `运动控制模块.md` - clipped notes for CyberDog motion-control APIs and LCM-based development.
- `code-mi/mine/pose_monitor.py` - ROS 2 node that monitors robot pose from Gazebo model states, odometry, or TF.
- `files/operations.txt` - local operation notes for launching the CyberDog simulation environment.
- `files/stone-road.png` - supporting image asset.

## Notes

Large downloaded installers, local application images, and empty placeholders are intentionally ignored.
