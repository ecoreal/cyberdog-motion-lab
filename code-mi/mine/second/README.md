# Second

路径：`second/`

`second/main.py` 当前实现的是“到位 + 两轮橙球检测撞击 + 收尾定位”的完整流程。

## 流程说明

按顺序执行：

1. 初始定位段
- 直行到 `y=0.81`
- 左移到 `x=2.655`
- 再直行到 `y=1.346`

2. 第一次转向与第一轮检测
- 转向到 `yaw=0deg`
- 第 1 次检测：在当前位置检测前方是否橙球  
  - 若是：前进撞击，再后退回原位  
  - 若否：直接进入下一点
- 左移到 `y=2.249`，第 2 次检测
- 左移到 `y=3.042`，第 3 次检测
- 左移到 `y=3.920`，第 4 次检测

3. 第二次转向与回扫检测
- 转向到 `yaw=-179.4deg`
- 回扫 4 次检测点（从大到小）：
  - `y=3.920`（当前位置先检）
  - `y=3.042`
  - `y=2.249`
  - `y=1.345`
- 每个点都执行“检测 -> 若橙则撞击+回退”

4. 收尾段
- 继续左移到 `y=0.900`（保持 `yaw=-179.4`，不再主动转向）
- 然后直走到 `x=0.196`
- 到达后停止并结束

## 视觉检测与撞击规则

- 相机话题：`/rgb_camera/image_raw`
- 颜色判定：HSV 橙色阈值 + 图像中心区域裁剪
- 检测结论：
  - `orange=True`：执行撞击（前进）+ 回退
  - `orange=False`：跳过撞击
- 在 `SCAN_BACK_*` 阶段会先停住，再做短时间连续检测确认，减少漏检。

## 控制细节

- 第一次转向后的左移扫描阶段，会做 `x` 轴微调，目标 `x≈2.655`。
- 回扫左移阶段同样做 `x` 轴微调（方向已按回扫姿态单独处理）。
- 回扫与收尾阶段默认不再主动转向（`wz=0`），避免原地转圈。

## 运行

在 `cyberdog_sim` 根目录：

```bash
source /opt/ros/galactic/setup.bash
source install/setup.bash
python3 second/main.py
```

## 关键日志

- `[PHASE] ...`：阶段切换
- `[CHECK] ... orange=... ratio=...`：每次检测结果
- `[HIT] ...`：触发撞击与回退
- `[DONE] ...`：任务结束位置
